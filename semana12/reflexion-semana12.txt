Durante este curso aprendí que la tecnología es una herramienta muy útil para fortalecer la participación ciudadana y la organización comunitaria. Conocí el uso de plataformas digitales para compartir información y comunicarme de manera responsable. También aprendí la importancia de verificar la información para evitar la desinformación. Además, comprendí conceptos básicos de HTML, JavaScript, Git y GitHub para crear y gestionar proyectos. Estos conocimientos me ayudarán a participar de forma más activa y responsable en mi comunidad.
